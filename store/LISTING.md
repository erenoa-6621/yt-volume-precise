## 1. 商品名（Item name）

```
YT Volume Precise
```

## 2. 概要（Short description・132文字以内）

```
YouTube の音量を数値で直接指定できます。よく使う音量はプリセットで1クリック。要求する権限は保存領域と YouTube だけで、外部への通信はありません。
```

## 3. 説明（Detailed description）

```
YouTube の音量スライダーは、細かい調整が難しい。
少し動かしただけで大きく変わるし、「前と同じ音量」に戻すこともできません。

YT Volume Precise は、音量を数字で扱えるようにします。

■ できること

・数値を直接入力する
  「50」と打てば音量 50。ゲージを目分量で合わせる必要がありません。

・プリセットで1クリック
  よく使う音量を登録しておけます（既定は 15 / 30 / 50 / 70 / 100）。
  この数値は自由に変更できます。

・100 を超えるブースト（最大 300）
  音が小さい動画のためのものです。既定は OFF で、明示的に ON にしたときだけ有効になります。

・プレイヤーの中で完結する
  YouTube のプレイヤー右下に小さなボタンが出ます。そこから開くパネルで全部の操作ができます。
  ツールバーのアイコンからも同じパネルが開きます。

・YouTube に馴染む見た目
  YouTube 自身のフォント・配色・角丸に合わせてあります。浮きません。

■ 権限について（この拡張を作った理由）

音量ブースター系の拡張は、多くが「すべてのサイトのデータを読み取る」権限を要求します。
音量を変えたいだけの対価としては、あまりに大きい。

この拡張が要求するのは次の2つだけです。

・保存領域（storage）── 設定を端末内に保存するため
・www.youtube.com と music.youtube.com ── プレイヤーの音量を操作するため

<all_urls> も tabs 権限も要求しません。YouTube 以外のページでは一切動きません。
外部サーバーへの通信コードは1行もありません。データを集めず、送りません。

これらは口約束ではなく、ソースコードに付属する検査スクリプトが機械的に検査しています。
検査が何を保証し、何を保証しないかも、包み隠さず文書に書いてあります。

■ ソースコード

すべて公開しています。上の主張はコードを読んで確かめられます。
https://github.com/erenoa-6621/yt-volume-precise

■ 正直に書いておくこと

・対応は Chrome / Edge（Chromium 系）です。Firefox には対応していません。
・100 を超えるブーストは、動画によっては音が割れます。元の音質には戻りません。
・YouTube 側の画面構成が変わると、プレイヤー内のボタンが出なくなることがあります。
  その場合もツールバーのアイコンからは操作できます。
・既知の制限は、リポジトリの KNOWN_GAPS.md にすべて並べてあります。

不具合や要望は GitHub の Issues へお願いします。
https://github.com/erenoa-6621/yt-volume-precise/issues
```

## 5. プライバシー タブの記入内容

### 単一用途の説明（Single purpose）

```
YouTube の再生音量を、数値入力とプリセットで正確に設定するための拡張です。機能はこの1点に限られます。
```

### 権限の正当性（Permission justification）

**`storage`**

```
利用者が設定した音量値・プリセットの数値・ブーストの ON/OFF・初回ヒントの表示済みフラグを、
利用者の端末内に保存するために使用します。保存先は chrome.storage.local のみで、
外部へは送信しません。この権限が無いと、タブを開き直すたびに設定が失われます。
```

**ホスト権限 `*://www.youtube.com/*` と `*://music.youtube.com/*`**

```
YouTube のプレイヤーの音量を読み書きし、プレイヤー内に音量操作パネルを表示するために必要です。
拡張の機能は YouTube の再生音量の操作のみであり、対象はこの2ホストに限定しています。
<all_urls> や tabs 権限は要求していません。ページの内容の読み取り・送信も行いません。
```

### リモートコードの使用

**「リモートコードは使用していません」を選ぶ。**
（拡張に含まれる JavaScript はすべてパッケージ内にあり、外部からコードを読み込みません。
CDN も eval も new Function も使っていません。）
